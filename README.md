# ПептидиМК — Пептиди во Македонија

Едукативен веб-сајт на македонски јазик за пептиди: што се, кои се најбарани,
каков е правниот статус во Северна Македонија и кои се реалните ризици.

Сајтот е **статичен** (HTML, CSS, JS без рамка и без build чекор), што значи
дека се вчитува брзо, работи на бесплатниот план на Vercel и може да се
уредува од било кој уред.

## Структура

| Пат | Што содржи |
| --- | --- |
| `index.html` | Целата содржина: основи, каталог, правен статус, безбедност, ЧПП, контакт |
| `styles.css` | Темата и целиот дизајн (темна палета, одзивен распоред) |
| `app.js` | Мени, филтер на каталогот, анимации, валидација на формата |
| `404.html` | Страница за непостоечки линкови |
| `assets/favicon.svg` | Иконата на сајтот |
| `vercel.json` | Заглавја, кеш и чисти URL-а на Vercel |

## Локално пуштање

Не е потребна инсталација:

```bash
npx serve .
```

или едноставно отвори `index.html` во браузер.

## Уредување на содржината

- **Нов пептид** — копирај еден `<article class="pep">` блок во `index.html` и смени
  ги `data-cat`, насловот, бejџот и текстот. Категориите се:
  `heal`, `hormone`, `metab`, `cog`, `cosm`, `immune`, `long`.
- **Нова секција** — додај `<section class="section" id="ime">` и линк во
  `.nav-menu` и во подножјето.
- **Контакт адреса** — во `app.js` замени ја константата `CONTACT_EMAIL`
  (`kontakt@peptidimk.mk`) со вистинска адреса. Формата е статична и отвора
  клиент за е-пошта; ако сакаш вистинско испраќање, поврзи ја со Formspree,
  Vercel Function или слична услуга.

## Деплој

Секој push на `main` автоматски објавува нова верзија ако проектот е поврзан
со GitHub во Vercel.

```bash
# рачно, од локалната папка
vercel          # preview
vercel --prod   # продукција
```

## Правна и здравствена рамка

Содржината е информативна и не претставува медицински или правен совет.
Проектот не продава пептиди и не содржи линкови кон продавачи. Пред да додадеш
нова содржина, задржи го тонот: наведи статус во Северна Македонија, наведи
ризик, не давај препораки за дозирање.
